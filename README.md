Crescendo Lab is a Taiwan-based, Asia-leading AI omnichannel customer communication software company (cresclab.com) serving 800+ global brands, and a LINE Biz-Solutions Gold Partner. Its platform spans MAAC (AI marketing automation), CAAC (conversational applications), and DAAC (data intelligence) across LINE, WhatsApp, SMS, email, and social channels. Its developer-facing surface is MAAC Go (sms.cresclab.com) — a self-serve, NCC-compliant Taiwan SMS API with a published OpenAPI spec, first-party Node/Python SDKs, a CLI, an official MCP server, and delivery webhooks. Surfaced as a 500 Global portfolio company and enriched into the API Evangelist network.

**Areas:** Company · SMS · Messaging · Marketing Automation · Customer Engagement · Taiwan · Omnichannel · MCP

### APIs (5)

- [Crescendo Lab Broadcast API](https://apis.io/apis/crescendo-lab/crescendo-lab-broadcast-api/) — Bulk (1-to-many) SMS. Small batches dispatch inline; >30 recipients queue asynchronously.
- [Crescendo Lab Contacts API](https://apis.io/apis/crescendo-lab/crescendo-lab-contacts-api/) — Address book with NCC-consent tracking.
- [Crescendo Lab SMS API](https://apis.io/apis/crescendo-lab/crescendo-lab-sms-api/) — Transactional (1-to-1) SMS send + status.
- [Crescendo Lab Teams API](https://apis.io/apis/crescendo-lab/crescendo-lab-teams-api/) — Cost-attribution teams. Tag sends with a team to see which team sent/spent how much (shared wallet — reporting only, not a wallet split).

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Crescendo Lab: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
